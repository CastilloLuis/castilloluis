### 🧠 What I do

- 🤖 **Agents & harnesses** — design agent loops, tool calling, MCP servers, and custom harnesses that run real work in production
- 🔌 **LLM integrations** — RAG, structured outputs, evals, and model orchestration wired into existing products
- 🚀 **AI-forward teams** — help teams adopt Claude Code, Cursor & agentic workflows: setup, conventions, prompts, and integration into their stack
- ✨ **Intelligent UIs** — streaming chat, generative interfaces, and real-time UX for AI products
